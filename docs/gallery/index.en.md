+## Reading an entry

- **Reported reproduction:** the source report describes a completed comparison;
  read its scope and limitations before reusing the model.
- **In progress:** implementation or validation is underway.
- **Scoped:** a reproduction objective is defined, but no completed result is claimed.
- **Blocked:** a required input or usable software environment is missing.

Model formats and software are described on the [Projects](../projects.md) page.
An entry does not imply certification in HS³, FlatPPL, or another format.
